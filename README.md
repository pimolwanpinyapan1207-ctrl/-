# ระบบติดตามเอกสารชุดเบิก

หน้าเว็บสำหรับบันทึกและติดตามชุดเอกสารเบิก: ส่งออกวันไหน ส่งแล้วหรือยัง ถึงลูกค้าวันไหน และใครเป็นผู้รับ

- เอกสารในชุดพร้อมจำนวน (ใบกำกับภาษี, ใบสั่งซื้อ/ใบสั่งจ้าง, คู่เทียบ, อากรแสตมป์ ฯลฯ)
- ส่งทาง EMS พร้อมลิงก์เช็คพัสดุไปรษณีย์ไทย
- รายงานประจำวัน คัดลอกชื่อลูกค้าและเลขพัสดุได้
- ส่งออกข้อมูลเป็น CSV เปิดใน Excel ได้
